# De zéro au code

Manuel de Python interactif, installable sur iPhone (Safari, Partager, Sur l'écran d'accueil) et utilisable hors connexion.

- `index.html` : l'app.
- `contenu.json` : les niveaux, leçons et exercices.
- `py/` : le moteur Python (Pyodide 0.26.4), hébergé ici pour marcher sans réseau.
- `sw.js` : garde tout sur le téléphone. Changer `CACHE` dans ce fichier quand on modifie les polices, les icônes ou le moteur Python.

La progression (XP, réponses, code) est gardée sur l'appareil, pas en ligne.
